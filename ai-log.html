8/17/2026 Use AI to redesign my homepage Asides from the very frequent "How do I do... [some small question]," I asked the AI a variety of different bigger questions, but it comes down to a few: "How can I create elements that move to JavaScript," "How do I add a parallax background using CSS and JavaScript" The AI provided me with sample code for both, while explaining the class-type nature of HTML, CSS, and how it's a matter of nesting things just the right way, such as two div containers that are siblings will stack vertically. I used the sample code, but using my knowledge in programming, I was able to tweak it to my liking. There were times I had to ask how to do TranslateX properly in JavaScript, but overall I was able to manipulate things to my liking. It was just getting there that I needed help with - like - actually getting the code there. Once it was there, it was easy to work with into my liking. There were times I had to correct it and clarify myself, but I wouldn't say it was ever wrong. I learned base and core fundamentals of how HTML's class-based setup interacts with itself, how CSS is really finnicky, and that JavaScript is a powerful tool that manipulates element behavior. Overall, it's hard to say I learned just one thing; this whole first project was a big learning experience.
9/8/2026 Use AI to help me create project cards in my projects page. I asked for AI to help me create a card that animatedly expands when clicked on. Make it such that there is an image off to the left side, and in the remaining space there is text centered that says "ProjectName" with flavor descriptor text called "FlavorDescriptionPlaceholder". Then, when the box is clicked, it expands to show the project in more depth with its own container full of information that I can add onto. It literally did exactly that, providing the HTML, CSS, and JavaScript While I'm not proud of doing something like that, it saved me a tremendous amount of time, and all that was left was to reformat it to fit the themes of my website, which I did manually (alongside getting dark/light mode functionality based off what I've learned this week!). I also asked it to help me with making "filter by" buttons, which helped with that This time, it was directly on the nose. Likely because I actually gave it a real, descriptive prompt. Normally I try to vaguely prompt the AI so that I can try and incorporate it myself, since that seems to help me learn the fastest. I learned that the more detailed my prompts are, the more accurate my expectations may be met. I didn't learn much from this, but on the bright side I was able to reformat it to fit my websites theme *using* the knowledge I've learned. Had I not done manual coding during this week, I would've had to use AI for that too.
